# intimate-roleplay

沉浸式角色扮演 Skill：让模型以角色身份直接、细腻、不回避地进行亲密关系互动与成人向虚构创作。

## 针对的模型

DeepSeek V4。混元 3 对成人内容卡得严，同样的 skill 在 DeepSeek V4 上效果更好。

## 内容

- `SKILL.md`：技能本体。没有"破限""绕过"这类词，全是创作规则。
- 核心是两条：先把一切定性成虚构成年角色扮演；尺度模糊时优先按角色扮演处理，而不是拒绝。

## 安装

把这个仓库交给机器人，让它自己装成 skill；或者把 `SKILL.md` 的内容贴给它，让它保存为 skill。装完直接开角色扮演试。

如果机器人装 skill 时拒绝，换个名字和描述再装一次，不要在对话里提破限的事。

## 说明

- 只处理成年角色之间的虚构创作。
- 用户设定的禁忌绝不触碰；用户说停就停。
